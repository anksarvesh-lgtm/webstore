what it clears

The stuff that piles up while you're not looking.

Logs, crash reports, old installers, font caches, and every per-app folder in ~/Library/Caches. How to clear cache on Mac covers which of these are worth deleting. macOS and your apps rebuild this stuff and almost never clean it up.

Xcode derived data, old simulators, and caches from Homebrew, npm, Docker, and VS Code. Plus build folders in old projects and worktrees AI agents left behind. Projects you're still working on are skipped.

Dragging an app to the trash leaves its caches, preferences, and containers behind. Purge clears them with the app, and finds leftovers from apps you already deleted.

Old downloads, leftover DMGs, duplicate copies, and local AI models from Ollama and LM Studio you stopped using. Exclude a folder and Purge won't look there again.

how it's different

Most cleaners try to find more. Purge tries to be sure.

Open source

Every line is public. Read it, fork it, or ignore us and audit it yourself. Purge on GitHub.

It doesn't guess

Some cleaners match files by name and hope. Purge only lists what it recognizes, and tells you why it's safe. See what it never touches.

Trash by default

Cleared files go to the Trash, so you can put them back. A few items, like iOS simulators and Time Machine snapshots, are removed for good.

App caches, Xcode derived data, and other developer tool junk, plus leftovers from apps you remove and large files or duplicates you pick yourself. One-click and scheduled cleans only touch items marked Safe to clean. It can also remove older Time Machine snapshots after you confirm. It keeps the newest one, and removed snapshots skip the Trash, so they can't be restored. Our system data guide covers the rest.

If you want. Scheduled cleaning clears Safe items on a schedule you pick, and Purge can review leftovers whenever you delete an app. Both are off by default.

Only a few things. Purge moves files to the Trash, and emptying it is a separate action you take yourself. iOS simulators, simulator runtimes, local Time Machine snapshots and Apple Intelligence models are the exceptions. Those are removed for good, not moved to the Trash.

Moving files to the trash doesn't free disk blocks. The space comes back when you empty the trash. Purge shows what's sitting in the trash so the number isn't a surprise. If system data in Storage barely moved, how to shrink system data covers what Purge didn't touch.

It won't guess. Purge never deletes permanently, never touches files it can't identify, and skips projects you're still working on. By default it quits when you close the window. For a fair comparison with paid suites like CleanMyMac, see our CleanMyMac comparison.
