Questions

Every single step checkpoint is atomically written to .agent/ledger.json and committed to git. When you reopen your agent and run task_status, Agent Guard resumes execution exactly from the last verified checkpoint.

Zero telemetry. Agent Guard operates 100% locally on your machine. No analytics, no phone-home servers, no telemetry pings. All state ledgers stay strictly within your local workspace.

Agent Guard invokes native macOS power assertion APIs (IOPMAssertionCreateWithName) to prevent system sleep while task steps remain in progress. As soon as all DAG steps are completed or canceled, the power assertion is instantly released.

Simply run ~/.agent-guard/dist/cli.js uninstall or remove the agent-guard entry from your IDE's mcp_config.json.
